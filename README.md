# Applicant Behavior Funnel Analytics (Task 8 - Final Task)

This repository holds the User Behavior and Conversion Funnel model built for my final module as a Data Analyst Intern at Internee.pk.
![Funnel Bottlenecks Graph](Output5.png)

### Project Objective:
The core target of this analytics framework is to track active user flow, calculate drop-off percentages at different layout phases, and isolate operational bottlenecks.

### Technical Stack Framework:
* **Python** (Data Analysis Core)
* **Pandas & NumPy** (For vectorizing metrics and math transformation rows)
* **Matplotlib** (For rendering the final horizontal conversion bar charts)

### Analytical Project Outcomes:
* Calculated specific retention rates dynamically across 4 core user behavior points.
* Generated clean functional charts showing where users drop out to help system designers optimize workflow setups.
